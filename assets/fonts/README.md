| `NanumGothic` | 나눔고딕 Light/Regular/Bold/ExtraBold |

각 글꼴의 저작권과 재배포 조건은 `licenses` 폴더를 확인합니다. 특히
가톨릭체는 개인과 가톨릭 교회기관의 비영리·사목 목적에만 사용할 수 있습니다.
박물관체와 서울체는 각 기관의 공식 배포본이며, 자세한 조건과 출처는
`MuseumClassic-LICENSE.txt`, `Seoul-Font-LICENSE.txt`를 확인합니다.

설정 키는 전체 UI `layout.fontFamily`, 툴바 전체
`layout.menuFontFamily`, 툴바 개별 `items[].fontFamily`, 언어 선택 전체
`languageSelection.fontFamily`, 언어 버튼 개별 `languages[].fontFamily`입니다.
