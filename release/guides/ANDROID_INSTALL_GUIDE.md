# 여의도성당Signage Android 최초 설치 가이드

## 패키지 구성

- `simple-kiosk.apk`: Android 설치 파일
- `INSTALL_GUIDE.md`: 현재 문서
- `MENU_CONFIG_GUIDE.md`: 메뉴·툴바·대기화면 설정 상세 가이드
- `SHA256SUMS.txt`: APK 무결성 확인용 SHA-256 값

## 설치 전 준비

1. 단말기의 날짜, 시간, 네트워크 연결을 확인합니다.
2. 기존 여의도성당Signage가 설치되어 있다면 운영 설정과 현재 버전을 기록합니다.
3. 이 프로젝트의 기본 Android 릴리스는 현재 **디버그 키로 서명**됩니다. 내부 설치
   테스트에는 사용할 수 있지만 외부 배포 전에는 조직의 정식 키스토어 서명 설정이
   필요합니다.

## 최초 설치

1. ZIP 압축을 풀고 `simple-kiosk.apk`를 Android 단말기로 복사합니다.
2. 파일 관리자에서 APK를 선택합니다.
3. Android가 요청하면 해당 파일 관리자에 대해 "알 수 없는 앱 설치"를 일시적으로
   허용합니다.
4. 설치가 끝나면 위 권한을 다시 해제합니다.
5. 여의도성당Signage를 실행하고 모든 메뉴, 네트워크, 가상 키보드 및 대기화면을
   확인합니다.

## 업데이트

- 기존 앱과 새 APK의 애플리케이션 ID 및 서명 키가 같으면 덮어쓸 수 있습니다.
- 서명 키가 다르다는 오류가 나오면 기존 앱을 제거해야 하며, 제거 시 앱 데이터도
  삭제됩니다.

## 사이니지 운영 권장사항

- 화면 고정 또는 전용 단말기 모드를 설정합니다.
- 자동 잠금, 절전, 시스템 업데이트 재부팅 시간을 운영 일정에 맞게 조정합니다.
- 메뉴와 URL 설정은 앱에 포함되므로 `assets/config/menu.defaults.json`을 변경했다면 새 APK로
  다시 빌드해야 합니다.
